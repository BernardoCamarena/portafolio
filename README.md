## 💻 Sobre este Proyecto (Portafolio Web)

Este sitio web fue construido para ofrecer una experiencia interactiva y fluida:

- **Next.js 16 (App Router)** & **React 19**
- **TypeScript** para tipado estático riguroso
- **Vanilla CSS Design System** con paleta de colores personalizada (Aurora gradients, tokens semánticos, modo oscuro)
- **Canvas interactivo** con animación por partículas
- **Soporte Bilingüe (i18n):** Español / Inglés sincronizado
- **Componentes interactivos:** Bento Grid responsivo, cursor magnético y animaciones de revelado

### Comandos de Desarrollo

```bash
# Instalar dependencias
pnpm install

# Iniciar servidor de desarrollo
pnpm dev

# Compilar para producción
pnpm build

# Ejecutar análisis de linter
pnpm lint
```
